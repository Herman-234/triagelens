# Privacy Policy — TriageLens

Last updated: 16 November 2026

TriageLens is a Forge app for Jira Cloud that shows a one-screen briefing for a Jira issue (status, blockers, linked issues, related Confluence pages, a suggested next action, and a status-update draft). It is also available as a Rovo agent and an MCP server with the same briefing tools.

## What the app accesses

- Jira issue data (summary, status, priority, assignee, dates, links, comments) and Confluence pages (via search for the issue key), through Atlassian's official APIs, using read-only scopes.
- The app only reads the data needed to build the briefing for the issue you are viewing. It does not read data from other sites or products.

## What the app stores

- **Nothing.** TriageLens does not store, copy, or cache personal data. It keeps no database of users, no account IDs, and no issue content on its own systems. Every briefing is built live from Atlassian's APIs and discarded after it is shown.
- The app sets no tracking cookies and sends no data to any third party.
